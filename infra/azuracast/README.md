# AzuraCast no se despliega en Vercel

AzuraCast se instala directamente en un VPS mediante su instalador oficial. Este repositorio no duplica `docker-compose.yml` ni imágenes del proveedor para evitar configuraciones obsoletas o divergentes.

Procedimiento operativo: [docs/instalacion-azuracast.md](../../docs/instalacion-azuracast.md).

Después de provisionar el servidor, documentar fuera de Git:

- proveedor e IP del VPS;
- dominio y contacto responsable;
- ubicación y frecuencia de backups;
- cuenta administradora de emergencia;
- fecha de la última restauración probada.
